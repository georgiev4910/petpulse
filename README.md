# PetPulse 🐾

Сладко и модерно PWA приложение за следене на грижите за домашни любимци.

## Функции (Beta v0.1)

- **Профил на любимеца** – име, порода, възраст, тегло, пол, тип животно
- **Множество стопани** – локално добавяне (синхронизацията идва по-късно)
- **Дневен тракер**:
  - Разходки (час, продължителност, локация)
  - Хранене (количество, вид храна)
  - Снакове
- **Здравен планер**:
  - Ваксини, обезпаразитяване, ветеринарни прегледи
  - Логове с бележки, следваща дата, ветеринар
- **PWA** – може да се инсталира на телефон
- **Локално съхранение** – данните остават в браузъра

## Стартиране

Просто отвори `index.html` в браузър или:

```bash
npx serve .
```

След това отвори http://localhost:3000
